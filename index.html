How the key gets found

1

Estimate the key length

The ciphertext is split into equal interleaved slices, one per candidate length from 1 to 12. English text repeats letters more often than random text, so the slice length where that repetition reappears — measured by the Index of Coincidence — points to the real key length.

2

Recover each letter

Each slice was shifted by one letter of the key, consistently. Trying all 26 possible shifts and scoring the result against standard English letter frequencies (chi-squared) reveals which shift — and so which key letter — fits best.

3

Put it back together

The recovered letters are assembled into a key, and that key decrypts the full ciphertext — no brute force, no dictionary, just public knowledge of how English text behaves.
